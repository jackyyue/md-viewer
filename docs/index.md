## 约定

- 一事一档：每个主题一个文档，完整拥有它，文档之间用链接不互相复制
- 整合不追加：新信息用于改进既有文档，不新开一段
- 过时的直接删，不留历史存档
- 不在此文件之外维护第二份索引
