# 术语表

一个概念只有一个词。本文件是权威口径：代码、文档、对话、issue 一律使用这里的词。

新增词条的时机：同一件事出现第二种叫法时，或某个词被反复解释时。

## 格式

```text
**词条**：
一句话定义。
_Avoid_：禁用同义词一、禁用同义词二
```

`_Avoid_` 是必填项。写不出禁用词，说明这个词还没有竞争性叫法，那就不必收进本表。

## 词条

**库根**：
启动时传入的那个文件夹，是整个程序的唯一边界；一切路径判断都以它为准。
_Avoid_：根目录、项目根、库目录、打开的文件夹

**大纲**：
当前这篇文档的标题列表（H1–H3），显示在最右侧一栏，点了跳到对应位置。
_Avoid_：目录、导航、TOC、侧栏

**库内链接**：
目标落在库根之内、且文件确实存在的 md 链接，点了在当前界面跳转。
_Avoid_：内部链接、站内链接

**库外链接**：
目标落在库根之外（或库内但文件不存在）的链接，显示为置灰不可点。
_Avoid_：外部链接、失效链接、坏链接

**越界**：
请求的目标落在库根之外。一律拒绝，不进业务逻辑。
_Avoid_：路径穿越、目录穿越、逃逸

**忽略名单**：
目录树里永远不显示的目录名（`node_modules`、`dist`、`build`、`.venv`）。点开头的目录不算在内，那是另一条规则。
_Avoid_：黑名单、排除表

**偏好**：
界面上可调、并且跨次启动记住的东西。目前只有两条分隔线的位置。
_Avoid_：设置、配置、选项

## 关系

- 一个库根对应一棵目录树；树里只出现目录和 `.md` 文件
- 链接的归属由库根判定：库内链接可点，库外链接置灰；请求的归属也由库根判定，越界一律拒绝
- 界面是三个栏：文件树栏、正文栏、大纲栏。两条分隔线各调一个栏的宽度，宽度记进偏好
- 偏好是全局的，不随库根变化

## 已裁定的歧义

- "目录" 曾被同时用于指文件夹和标题列表。裁定：文件夹叫"目录"，标题列表叫"大纲"。中文里这两个意思都常用，而界面上两者并排出现，必须分开
- 英文代码里的 `panel`（如 `#outline-panel`）对应中文的"栏"，是同一个概念的中英两种写法，不算竞争叫法，不因此改 id
- "库外" 与 "越界" 不是同义词：库外描述位置（库外链接），越界描述事件（一个请求越界了）。前者是名词性的分类，后者是动作性的判定
- "配置" 有两个不冲突的用法：骨架的「项目配置」一节指项目法律的一部分（冲突时以它为准），"零配置" 指程序不需要用户先做设置。两者都不是界面上可调的偏好，偏好一律叫"偏好"
